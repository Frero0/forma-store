# Assets and dependency rights

All product SVG illustrations in `public/products/` were drawn for Forma using geometric paths. They are local illustrations of fictional demonstration products, not manufacturer photography. Product descriptions, specifications, prices, variants and stock are demonstration content.

Lucide icons retain their ISC licence. React, Vite and other dependencies retain their package copyright notices and licences. Refer to the LICENSE files distributed with the installed packages.

No project-wide open-source licence has been assigned to the application code. No LICENSE file was found in the starting application. Existing sensitive configuration is excluded from version control and is not required by the rewritten application. No legacy commercial SDK or external product imagery is distributed by the new app.
